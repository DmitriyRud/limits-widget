# /sdd-plan — технический план

1. Найди папку `specs/$ARGUMENTS*`. Если `spec.md` не `status: approved` — остановись и попроси человека утвердить спеку.
2. Если в спеке есть внешние источники данных без подтверждённых фактов — запусти субагента
   `provider-researcher` (по одному на источник, параллельно). Результаты — в `research.md` с ✅/⚠️.
3. Делегируй план субагенту `architect`: на вход spec.md, research.md, constitution.md, текущая структура `Sources/`.
4. Проверь план:
   - каждый FR/NFR покрыт компонентом в таблице «Компоненты и файлы»;
   - нет новых зависимостей без ADR;
   - `LimitsCore` остаётся без AppKit/SwiftUI;
   - «Проверка конституции» заполнена.
5. Если решение архитектурное — создай ADR в `docs/adr/` из ADR-0001 как образца.
6. Оставь `status: draft`, перечисли пользователю ключевые решения и риски.
