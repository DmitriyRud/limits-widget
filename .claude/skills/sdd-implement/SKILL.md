# /sdd-implement — реализация по задачам

1. Открой `specs/<NNN>*/tasks.md`; он должен быть `status: approved`. Прочитай `plan.md` и `spec.md` целиком.
2. Выбери задачи: указанные в `$ARGUMENTS`, иначе — первую незакрытую фазу.
3. Для каждой задачи:
   - тестовые задачи (фаза 2) → субагент `test-writer`; убедись, что новые тесты **падают** (`scripts/test.sh`);
   - задачи реализации → субагент `swift-implementer` (передай ID задачи, требования, пути файлов);
   - независимые `[P]`-задачи можно запускать параллельно разными субагентами;
   - после задачи: `swift build` и `scripts/test.sh` зелёные → отметь `[x]` в tasks.md.
4. Если реализация требует отойти от плана — **остановись**, опиши отклонение в `plan.md` → «Отклонения»
   и спроси человека.
5. Для задач, затрагивающих `Providers/` или учётные данные, в конце фазы запусти субагента `security-reviewer`.
6. Итог пользователю: закрытые задачи, результат тестов, что дальше. Коммит — только по просьбе пользователя.
