# /sdd-specify — спецификация фичи

1. Прочитай `specs/constitution.md` и `specs/templates/spec-template.md`.
2. Определи номер: следующий после максимального `specs/NNN-*`. Имя — 2–4 слова kebab-case.
3. Если описание фичи неполное, задай пользователю **до 3** уточняющих вопросов (кто пользователь, критерий
   успеха, что вне рамок). Остальное помечай `[NEEDS CLARIFICATION]`.
4. Делегируй черновик субагенту `spec-writer`, передав: описание `$ARGUMENTS`, ответы пользователя, путь к папке.
5. Проверь результат:
   - нет упоминаний технологий (Swift, классов, эндпоинтов) — они идут в plan.md;
   - у каждого FR/NFR есть проверяемый критерий;
   - секция «Соответствие конституции» заполнена честно.
6. Оставь `status: draft`. Сообщи пользователю путь и список открытых вопросов.
   Следующий шаг — `/sdd-plan NNN` после того как человек утвердит spec (`status: approved`).
