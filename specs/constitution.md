# Конституция проекта Limits Widget

Неизменяемые принципы. Любая спецификация, план или код, противоречащие им, отклоняются.
Изменить конституцию можно только явным решением владельца проекта (с записью ADR в `docs/adr/`).

## I. Spec-Driven Development
1. Код пишется только по утверждённой спецификации: `specs/NNN-*/spec.md` → `plan.md` → `tasks.md`.
2. Статусы документов: `draft` → `approved` → `done`. Утверждает человек, не агент.
3. Любое отклонение от плана при реализации сначала фиксируется в `plan.md` (раздел «Отклонения»).
4. Каждая задача в `tasks.md` ссылается на требование (`FR-xxx` / `NFR-xxx`) из `spec.md`.

## II. Безопасность учётных данных (не обсуждается)
1. Токены и ключи **никогда** не логируются, не печатаются, не пишутся на диск и не попадают в контекст агента.
2. Приложение только **читает** учётные данные агентов (Keychain, `~/.codex/auth.json`); никогда их не изменяет и не обновляет.
3. Токен отправляется только на официальный хост своего провайдера (Anthropic → `api.anthropic.com`, OpenAI → `chatgpt.com`/`api.openai.com`). Никакой телеметрии и сторонних серверов.
4. Предпочтение — локальным источникам без сети (логи сессий), если они дают те же данные.

## III. Нативность и простота
1. Swift 6 + SwiftUI, macOS 14+. Только системные фреймворки, без сторонних зависимостей (исключения — через ADR).
2. Сборка без Xcode-проекта: `swift build` / `swift test` (Swift Package Manager).
3. Виджет потребляет < 1% CPU в простое и < 50 МБ RAM; опрос не чаще 1 раза в 60 с на провайдера.

## IV. Расширяемость провайдеров
1. Каждый ИИ-агент — отдельная реализация протокола `LimitsProvider` в `Sources/LimitsCore/Providers/`.
2. UI не знает о конкретных провайдерах — только о модели `ProviderSnapshot`/`UsageWindow`.
3. Ошибка одного провайдера не ломает отображение остальных.

## V. Тестируемость
1. Весь парсинг и расчёты (время до сброса, проценты) — в `LimitsCore` и покрыты unit-тестами на фикстурах.
2. Фикстуры — обезличенные реальные ответы; никаких настоящих токенов/ID аккаунтов в репозитории.
3. Сеть и Keychain абстрагированы протоколами и подменяются в тестах.
